# Zebra Consultancy Services

Website for **Zebra Consultancy Services**, a web design and development studio: https://zebraconsultancyservices.com

Plain static site (HTML, CSS, a little JavaScript). No build step.

## Files

- `index.html` – the single page
- `styles.css` – all styles
- `script.js` – mobile menu and contact form (opens the visitor's email app addressed to contact@zebraconsultancyservices.com)
- `zcs-mark.svg` – ZCS logo mark (light, for dark backgrounds)
- `favicon.svg` – site icon (Z from the logo)
- `vercel.json` – clean URLs and basic security headers

## Run locally

```sh
npx serve .
```

## Deploy

Hosted on Vercel. Every push to `main` deploys automatically.
